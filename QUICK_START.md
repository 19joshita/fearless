# Quick Start - 3 Steps ⚡

## Step 1: Install (1 minute)

```bash
npm install react-native-compressor
cd ios && pod install && cd ..
```

## Step 2: Run (2 minutes)

```bash
npm run ios
# or
npm run android
```

## Step 3: Test (1 minute)

1. Open support chat
2. Select a video
3. Watch:
   - ✅ Loader appears instantly
   - ✅ "Compressing... 25%"
   - ✅ "Uploading... 75%"
   - ✅ "Complete! 100%"
